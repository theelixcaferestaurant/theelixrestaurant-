# THE ELIX dashboard: quick guide

Open `/admin` and sign in. Left menu:

| Page | What you do there |
|---|---|
| Overview | Live counts of menu items and reviews, recent reviews, recent admin activity |
| Menu management | Add / edit / delete items, change price, photo and video, order (↑ ↓), Featured, Available / Temporarily unavailable, schedule |
| Categories | Edit the four category names, intro text and subcategories |
| Reviews | Approve, Hide, Reject, Restore, Delete; tabs Pending / Approved / Hidden / Rejected; search; average rating |
| Website media | Hero video, banners, page photographs, category pictures (preview first, then Publish) |
| Gallery | Gallery photos and videos |
| Website content | Homepage, About and brand wording |
| Restaurant details | Address, phone, email, social links |
| Opening hours | Hours per weekday, closed days, holidays, temporary closure banner, daily timings |
| Take Away slides | Replace, add, delete, rename, reorder, publish / draft the Take Away menu pages |
| Backup & recovery | Save restore points, download / upload a backup file, restore menu, slides, gallery or restaurant details |
| Admin account | Change password, sign out of all devices |

## Menu availability
* **Mark unavailable**: the item stays on the menu with a "Currently Unavailable" label. **Make available** reverses it.
* Inside an item you can also set **Unavailable until** (it comes back by itself) and **Served from / until** (daily hours).
* All times are India time (Asia/Kolkata), whatever device the customer uses.
* **Hide** (different from unavailable) removes the item from the website completely.
* Each action changes only that one item.

## Reviews
New reviews are Pending and are not public. Approve publishes. Hide removes it from the website but keeps it. Reject marks spam. Restore puts a hidden review back. Delete is permanent (asks first).
